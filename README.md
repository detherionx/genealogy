# Hofmann family of Vockenhausen

A small static family-history site: ancestors from Vockenhausen (Eppstein, Taunus) and Immelborn (Thuringia), built only from civil-register entries.

Open `index.html` through any static server (e.g. `python -m http.server`) or GitHub Pages.

## Files

- `data.js` – people, facts, sources, open questions. Edit here.
- `scans/` – web copies of the published register entries (all over 80 years old).
- `index.html` – renders the data.

## Rules

- Every fact cites a source and carries a status: `record` (read from the scan), `probable`, or `hypothesis`.
- Living people are not published. Estate papers, correspondence and recent certificates stay private; only facts from them may appear.
- Read dates and places from the scan itself, not from earlier transcriptions.
